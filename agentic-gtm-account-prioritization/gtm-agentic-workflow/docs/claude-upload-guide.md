# Claude Artifact upload guide

The prepared upload bundle is `outputs/claude-artifact-interview-upload.zip`. It contains the prompt, architecture SVG, product brief, interview walkthrough/Q&A, and standalone demo HTML. Upload those files to a Claude conversation where Artifacts are available, then ask it to build an editable Artifact using `claude-artifact-prompt.md` as the specification.

The working directory `outputs/claude-artifact-interview-upload/` contains the same files if you prefer selecting them individually. All demo records are fictional; do not add internal exports or API credentials.
